**Up to 8 players**, plus fixes from the first 0.8.0 sessions. Game version 1.5.3.2.

> **Pre-release.** 0.8.0 was played by two people over Steam; the changes below compile but have not been played yet, and 3+ players have only been simulated.

## Install

Download `SoulstoneCoop-0.9.0.zip` and extract it into the game folder (Steam → right-click the game → Manage → Browse local files) so that `winhttp.dll` and `BepInEx/` sit next to `Soulstone Survivors.exe`. Launch from Steam. Full steps are in `README.txt` (English) and `LEIA-ME.txt` (Portuguese) inside the zip.

**Everyone needs 0.9.0**: it does not connect to 0.8.0.

## New

- **Up to 8 players** (1 host + 7 guests). The host keeps owning the world and relays each player to the others. Invite more friends from the Co-op tab; the panel lists everyone in the lobby.
  - Any ally standing next to a downed player revives them; the run is lost only when everyone is down.
  - Anyone's pause freezes everyone; the host can unpause for all (closing their own pause, or F4).
  - A guest who surrenders leaves alone; the host surrendering ends the run for all.
  - Optional `[Coop] EnemyScalePerPlayer` (off by default; try `0.25`) adds more enemies per extra player.
  - `[Coop] MaxPlayers` (default 8) caps the lobby; `[Coop] ReplicaCastRadius` (default 60) skips drawing far-away partners' skills to keep 8-player fights smooth.
  - If a friend of a guest can't join the lobby, set `[Coop] LobbyType = Public` on the host.
- **Level-up overlay:** the upgrade panel opens small and see-through at the bottom of the screen, and you keep moving and attacking. Pick with 1–4, Tab hides it. `[Coop] LevelUpPause` switches back to pausing.
- **Your partners' pets and summons are visible**, including the Sentinel's panther.
- **Partners' dashes show** on their character.

## Fixed

- Partners slid around without animations (since 0.8.0).
- Partners showed up without their weapon.
- Remote skills: the replica caster now sticks to the partner before each cast, so skills come out of them (please report if a partner's skills are still invisible: the log now records where replicas spawn).
