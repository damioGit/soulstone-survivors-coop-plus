Guests reconnect to a run after a dropped link, the map quests work for guests (Valentine altars, Easter eggs, boss runes and their portals), and quest rewards reach the guests. Game version 1.5.3.2.

**Everyone needs 0.13.0**: it does not connect to 0.12.0 or older.

## New

- **Reconnect in a run**: when a guest loses the host in the middle of a run (a Steam session that fails, the host's packets stopping for 30 s), the run no longer ends. The guest tries to get back for up to 2 minutes ("Lost the host - reconnecting... (114 s)") and comes back into the same run with its character, level and items. The host resends the enemies, and the shared XP gained meanwhile is added. If the host doesn't come back in 2 minutes, the run ends as before. No attempt is made when the host quits on purpose or the guest presses Disconnect. Over Steam, the guest stays in the lobby while it tries, and the host takes back a player of the current run even though the lobby is closed during runs. Tested over direct IP; the Steam path still needs a real drop to confirm it.
- **Map quests for guests**:
  - **Valentine altars** (Forest): guests can break the altar trigger, the Cupids shoot at guests too, and the altars are the host's ones (no second, separate copy any more).
  - **Easter eggs** (Cavern): guests see the eggs and the drop-off, pick eggs up by standing on them, carry up to 8 of their own and deliver them; the host's carried eggs and speed are not affected.
  - **Boss runes** (Snow): guests see the 5 runes, and a soulstone of the right colour collected near one lights it up for everyone.
  - **Quest portals**: the portal these quests open (to the Ice Cavern or the Mine Cavern) is shown to the guests, and walking into it takes the whole group there.
- **Quest rewards for guests**: when the quest is completed, each guest gets the same reward on its own profile. For the Valentine altars, that is the achievements that unlock the active skills Heartbreak Orbs, Camor's Arrow and Heartrending Strike.
- **Players joining a run in progress** (Co-op options → Join a run in progress) get the XP the group already has, instead of starting from level 1.

## Fixed

- **Doubled quest objects for guests**: each side drew its own quest, so guests saw a second altar or cage (sometimes from another quest) next to the host's.

## Known limits

- A guest carrying eggs is not slowed down.
- After a reconnect the guest's level matches the host's, but its XP within the level can be a little behind.
- If the host takes a portal while the guest is away, the guest stays on the old map.
