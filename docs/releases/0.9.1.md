Fixes from a code review of 0.9.0. Game version 1.5.3.2.

> **Heads-up:** like 0.9.0, these changes compile but have not been played yet.

**Everyone needs 0.9.1**: it does not connect to 0.9.0 or older. Install the same way: extract `SoulstoneCoop-0.9.1.zip` into the game folder over the previous version.

## Fixed

- A guest who surrendered was still pulled along by the host's victory, Home portal and Endless/challenge portals (also with 2 players).
- The host pressing Disconnect mid-run left the guests' helper entities on the map, and every enemy death after that logged a loot error.
- With `[Coop] AllowRejoin`, a guest who surrendered and returned to the menu was pulled back into the run.
- A guest who left the run could keep the others from losing when everyone else was down.
- `[Coop] EnemyScalePerPlayer` could lower a game limit that was already above 200; it now only raises limits.
- Closing the host's pause menu only releases Esc pauses; F4 still releases everything.

## Known issue

- Over Steam, a guest who quits and rejoins with the same account within ~15 seconds (before the host notices the drop) gets no player slot: they can't be revived and get no XP orbs. Disconnect, wait about 15 seconds, then join again.

See the [0.9.0 notes](https://github.com/gskolber/soulstone-survivors-coop/releases/tag/v0.9.0) for everything new in the 0.9 line (up to 8 players, level-up overlay, visible pets and summons).
